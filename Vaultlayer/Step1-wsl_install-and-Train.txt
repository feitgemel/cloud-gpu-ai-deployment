1. Environment Setup in Anaconda Prompt 

# Run PowerShell and wsl for Linux envoriment 

Run poweshell
wsl


conda create -n vaultlayer_cards python=3.11 -y
conda activate vaultlayer_cards



2. Install the VaultLayer CLI tool:
pip install vaultlayer



3. Perform a one-time account authentication (this will launch your browser to authenticate):

Goto https://vaultlayer.cloud/
Generate Token : vl_live_c1de19axxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Run this in the terminal:
vaultlayer init


4. Preparing Project Files

Create a dedicated project directory on your local system
 (e.g., C:\tutorials\VaultLayer_vit_cards_project) :

Go to c:/tutorials
mkdir VaultLayer_vit_cards_project
cd VaultLayer_vit_cards_project

- Copy the dataset (images) to the working wolder and name it "cards_dataset"
- Copy the following two files to the working folder:

- requirements.txt
- train.py
- Step2.txt
- Step3-Test-The-Model-6-random-images.py



#5. Dataset Upload & Remote Execution

#You can set a hard spend threshold in USD for the run. If training spend reaches this limit, VaultLayer auto-cancels the job:

vl run --max-cost 10 --data cards_v2 Step1-train.py
